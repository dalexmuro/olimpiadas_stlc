How Agentic Delivery stayed deterministic

Building real software with coding agents is an engineering discipline, not prompt luck. Every increment followed a repeatable governance loop.

1. Executable Specifications

Functional, technical, organizer, and deployment contracts live in bilingual Markdown (AGENTS.md, PRODUCT.md, docs/) so agents and humans share one source of truth.

2. Mandatory Verification Gates

No step finishes without passing unit tests (npm test), ESLint, and strict TypeScript checking (tsc --noEmit), followed by human-reviewed Git commits.

3. Independent Pre-Public Audit

Before open-sourcing, the repository underwent a read-only multi-lens audit with independent subagent verification across security, privacy, architecture, and open-source readiness.

4. Continuous Security Gates

Local pre-commit.com hooks and GitHub Actions run Gitleaks full history scans, custom PII/DB-dump guards, and production dependency audits on every push and pull request.

Serverless Edge Architecture

Designed for near-zero operational cost, global low latency, and strict America/Caracas (UTC-4) contest scheduling.

Runtime

Next.js 15 + Cloudflare Workers

App Router compiled via OpenNext Cloudflare, wrapped by a custom src/worker.ts entrypoint connecting both HTTP SSR and Cloudflare Cron scheduled() triggers.

Data & Media

Cloudflare D1 + Drizzle ORM + R2

16 normalized SQLite tables with parameterized queries, idempotent migrations, and R2 media storage validated by binary magic bytes and nosniff.

Identity

Better Auth + Rolling Timeout

Email/password verification, Google & Microsoft OAuth, fail-closed signing secrets, and banking-style 10-minute closed-tab / 15-minute idle session expiration.

Editorial Engine

Myers Diff, Blind Voting & Brevo

Word-level similarity checking, deterministic anonymous ballot shuffling (fnv1a32), parametric 50-participant jury multiplier formula, and 26 editable Brevo email templates.

Security & Governance Highlights

Hardened for public open-source release under the MIT License.

Verified in CI

Fail-Closed Auth & Constant-Time Cron

Production deployments refuse to boot without BETTER_AUTH_SECRET; manual cron calls require a separate CRON_SECRET compared via Web Crypto SHA-256 constant-time equality.

Defense in Depth

Sanitized Rich Text & HTTP Headers

WYSIWYG admin editors sanitize HTML on write and render, backed by CSP, HSTS, X-Frame-Options: DENY, and X-Content-Type-Options: nosniff.

Shift-Left Protection

Pre-commit + Gitleaks Full History

Blocks .env*, unauthorized SQL/DB dumps, private keys, connection strings, and participant PII both in the Git staging area and across full Git history in CI.

Cómo mantener determinista el desarrollo con IA

Construir software real con agentes de código es disciplina de ingeniería, no improvisación. Cada avance siguió un ciclo verificable.

1. Especificaciones ejecutables

Reglas funcionales, técnicas, operativas y de despliegue en documentación bilingüe (AGENTS.md, PRODUCT.md, docs/) como única fuente de verdad para agentes y desarrolladores.

2. Puertas de verificación obligatorias

Ningún paso cierra sin 100 % verde en pruebas unitarias (npm test), ESLint y tipado estricto (tsc --noEmit), con commits revisados y ejecutados por el ingeniero responsable.

3. Auditoría independiente pre-publicación

Antes de abrir el repositorio, se ejecutó una auditoría integral de solo lectura con verificación independiente por subagente sobre seguridad, privacidad, arquitectura y estándares open-source.

4. Security Gates continuos

Hooks locales con pre-commit.com y GitHub Actions ejecutan Gitleaks sobre todo el historial Git, guardas de PII/volcados de BD y auditoría de dependencias en cada push y pull request.

Arquitectura Serverless Edge

Optimizada para costo operativo mínimo, baja latencia global y transiciones exactas en hora oficial de America/Caracas (UTC-4).

Ejecución

Next.js 15 + Cloudflare Workers

App Router compilado con OpenNext Cloudflare y envuelto en un punto de entrada src/worker.ts que conecta SSR HTTP y triggers Cron scheduled().

Datos y Media

Cloudflare D1 + Drizzle ORM + R2

16 tablas SQLite normalizadas con consultas parametrizadas, migraciones idempotentes y almacenamiento R2 validado por magic bytes binarios.

Identidad

Better Auth + Cierre por Inactividad

Correo/contraseña con verificación, OAuth con Google y Microsoft, secretos fail-closed y expiración bancaria de 10 min con pestaña cerrada / 15 min por inactividad.

Motor Editorial

Myers Diff, Voto Ciego y Brevo

Similitud palabra a palabra, orden anónimo determinista (fnv1a32), fórmula automática de multiplicador del jurado (cada 50 participantes) y 26 correos editables con WYSIWYG.

Seguridad y Gobernanza Open-Source

Endurecido para publicación pública bajo Licencia MIT.

Verificado en CI

Auth Fail-Closed y Cron en tiempo constante

Producción bloquea el arranque si falta BETTER_AUTH_SECRET; el endpoint operativo de cron usa un CRON_SECRET independiente con comparación SHA-256 en tiempo constante.

Defensa en profundidad

Editor WYSIWYG sanitizado y cabeceras HTTP

Los editores de texto enriquecido sanitizan HTML al guardar y renderizar, respaldados por CSP, HSTS, X-Frame-Options: DENY y X-Content-Type-Options: nosniff.

Protección Shift-Left

Pre-commit + Gitleaks en historial completo

Bloquea .env*, volcados SQL/BD, claves privadas, connection strings y datos personales de participantes tanto en el staging area local como en todo el historial Git en CI.
